# PyYTmp3

A small TUI python program that converts YouTube URLS to mp3 files.

## Python

```bash
python3 main.py
```

The URL can be a video or a playlist link.

If you want to get multiple videos, just enter all the URLS separated with space bars.

If you have a private playlist, you can use the JavaScript program to convert the playlist into multiple URLS.

## JavaScript

Drag the JavaScript program into your bookmarks bar. It works on chromium browsers. I am not sure about Firefox.

When you are in the playlist page. You will see a list of videos. Click on the bookmark.

Wait a couple of seconds and videos the URLS will be copied to clipboard.
